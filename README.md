# Healthy Gut AI — n8n SEO Article Generator

This repo contains n8n workflows, prompts, and utilities for generating SEO-optimized medical articles for Healthy Gut AI.

## Step 1: Repo skeleton
Folders:
- n8n-workflows/   (exported n8n JSON files)
- prompts/         (Prompt 1 and Prompt 2)
- scripts/         (validator and metrics collectors)
- examples/        (generated article examples)
- demo/            (demo video script and assets)

## Environment
Create a `.env` or use your n8n credentials for API keys:
- GEMINI_API_KEY=
- GROQ_API_KEY=
- GITHUB_TOKEN=
